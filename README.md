# Shooter Jet Game

A JavaScript shooter game implemented using the Module Pattern with proper encapsulation and memory management.

## Features

- ✅ Module Pattern (IIFE with closure)
- ✅ Private score variable with public methods
- ✅ Proper 'this' context binding
- ✅ Game Over and Restart states
- ✅ Memory leak prevention with proper cleanup
- ✅ Event listener management (addEventListener/removeEventListener)

## How to Play

1. Open `index.html` in a web browser
2. Use **Arrow Keys** to move your jet
3. Press **Space** to shoot
4. Destroy enemy ships to increase your score
5. Avoid collisions to stay alive
